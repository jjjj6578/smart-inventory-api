# Smart Inventory API (M604 Advanced Programming)

A robust Spring Boot RESTful API designed to manage and track inventory items efficiently with an H2 in-memory database and global error handling.

## Features
- **RESTful Endpoints**: Full CRUD operations for inventory items.
- **Database**: In-memory H2 database integration with automatic schema creation.
- **Error Handling**: Comprehensive custom exceptions and a global exception handler for stable responses.

## Tech Stack
- **Java 21**
- **Spring Boot**
- **Spring Data JPA / H2 Database**
- **Maven**
